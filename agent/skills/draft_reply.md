# Draft a concise reply

1. Restate the ask in one line (internally) so the answer stays on target.
2. Lead with the answer or decision, then supporting bullets.
3. Include links/paths only when they help the reader act.
4. End with a single clear ask if human input is still required; otherwise stop.
5. Match the channel: Slack = short paragraphs; GitHub comments = scannable markdown.
